# 首页与关注界面的复用核查

核查范围：首页、关注页、两种详情、创作者资料页、搜索与合集的当前 React 实现。
本记录区分同一交互的重复实现和领域数据差异，不代表全仓库重复代码扫描。

## 本次处理

| 位置 | 判断 | 实现 |
| --- | --- | --- |
| 卡片创作者头像 | 头像按钮和创作者链接具有相同 hover 反馈 | 共享选择器同时支持按钮和链接；作者资料页的在线卡片同步生效 |
| 详情创作者身份 | 来源身份已有唯一实体绑定时，可作为资料页入口 | 两种详情共用 46px 头像、下方姓名和身份标题样式；关注入口使用 `FollowAuthorLink`，保留组合键和键盘焦点 |
| 详情下载动作 | 下载由浏览器链接执行，几何与同排按钮一致 | 舞台操作键样式同时接纳下载链接；禁用态使用共享颜色 |
| 接着看 | 推荐带的展示、数量设置和横滚是相同语义 | 两种详情共用 `RelatedSection`；关注卡片使用 `FollowCard` 的 `next` 版式 |
| 详情底部 | 分集队列和后续推荐是两个可独立横滚的区域 | 共用 `DetailContinuation`，桌面并排、手机上下排列；同底色、细分隔线，卡片悬停面保留 8px 空间 |
| 分卷头像 | 分卷和版本接口提供详情 `entity_refs` | `cardIdentity` 和队列头像读取对应实体引用，图像版本和取景由 `avatarInner` 处理 |
| 卖家署名与头像 | 本地作品身份引用提供可信角色和可用代表作 | 卡片、队列和详情优先实体图，再用代表作画面并提示「非本人」；详情按可信卖家角色分组，与厂牌共用自动换行区域 |

关注推荐使用已有只读分页接口与共享缓存，优先同创作者和共同标签，排除当前合集、已看、
忽略和不同媒体；每次最多读取三页。列表、详情的状态更新同步推荐缓存，换推荐条目保留返回地址。
本地推荐仍使用 `/api/related` 的 Tag IDF / MMR，关注数据不套用本地资产 ID。

## 仍有重复的候选

| 位置 | 证据 | 后续边界 |
| --- | --- | --- |
| 顶部头像与题材筛选项 | [catalog-filter.css](../frontend/src/react/catalog-filter/catalog-filter.css) 与 [follow-feed.css](../frontend/src/react/follow-feed/follow-feed.css) 分别定义 76px 单元、48px 头像、hover、按下和焦点 | 可共用展示层；人物／厂牌与创作者／题材的取数和筛选语义分别保留 |
| 图片墙布局 | [entity-body.css](../frontend/src/react/entity-body/entity-body.css) 与 [follow-feed.css](../frontend/src/react/follow-feed/follow-feed.css) 重复 5／3 列及 1400、1000、640px 断点；普通／手机间距分别为 10／8px 与 14×10／12×8px | 可共用列数和断点；关注卡片含署名及操作，本地图片格不含，间距是否统一需按这种内容差异决定 |

## 已共用的能力

- 首页和资料页筛选工具行共用 `entity-filter` 的控件与样式。
- 搜索结果使用 `CatalogGridPage` 和 `MediaCard`。
- 本地、关注的合集和多媒体队列使用 `MixQueue`、`MixQueueRow`。
- 自动续页使用共享 `LoadMore`；关注达到 500 组后改为手动加载属于领域规则。
- 标签来源类型、在线媒体代理、本地播放与关注播放的取数差异属于领域职责，不能仅凭外观相似合并。

## 影响面

页面、缓存状态、桌面和手机、组件与浏览器回归适用。本地作品身份引用提供代表作头像与可信角色，没有迁移、
真实 ledger 写入或新依赖。入口与智能体规则不变，中英文 README 说明两种详情的推荐入口。
生产切换与验证以本次运行回执为准。
