# 标签词表审查

核验日期：2026-10-11。来源：本机 ledger 查询、`genre_taxonomy`、`catalog_rules`、共享显示模块 `frontend/src/core/tags.ts` 与已授权归一回执。

本记录不登记进 `docs/reference-sources.json`：它是本机账本与映射实现的审查、执行记录，没有可重新抓取的上游原文 URL。

## 审查结果

- 账本共有 1,645 个标签名称，其中 1,409 个为 `演员:` 兼容标记，236 个为实际标签；标签实体也为 236 个。
- 截图中的 `OL` 是 `OL制服` 的界面显示名。`OL制服` 表达着装，`秘书OL` 表达角色，两者保留独立筛选。制服使用完整名称，并归入外观分组；`JK制服` 采用相同口径。
- 来源词 `OL`、`Office Lady`、`Secretary` 共用 `秘书OL`；手动添加退役名称通过 `current_tags` 归一，详情缓存、最近使用和撤销采用 API 返回的规范名。
- `猫耳` 与 `貓耳女` 共用具体标签 `猫耳`。`兽耳兽装` 是独立的宽泛着装标签。
- 来源映射的规范化键未发现冲突。现有退役标签名在实际标注中的存量为零。
- 用户授权的 22 条本地 NFO 标注已归一，涉及 11 部作品：19 条改为规范名，3 条去重；归属均为 `javinizer:local_nfo:tag`。10 个旧标签实体并入对应实体，原词保留为别名，旧实体 ID 保留重定向。
- 「其他内容」分组共有 24 个名称，包括平台出处、自定义标记和未收录的描述，如 `Iカップ`、`グリグリ`、`テカテカ`、`個撮`、`未公開`、`無編集`、`神乳`、`長編`；没有足够依据时保留原词，不据字面猜测合并。

## 影响面

- 数据层：扁平标注、标签实体、作品关系、别名及重定向同步归一，来源快照与其他表数据保持完整；无 schema 修改。
- API：`/api/item/tag` 的 `tag` 返回规范名；隐藏采用请求中的具体名称，保留来源证据。
- 页面：共享标签显示覆盖首页、详情、沉浸、实体页、标签页和统计；手动添加、最近使用及撤销共用规范名。其余页面没有独立映射。
- 反向状态：添加后的撤销使用服务端返回的标签身份；规范标签已经存在时，添加同义词不提供撤销原标签的操作。
- 视口与测试：本次未修改界面布局，桌面与 390×844 手机浏览器未单独验证；以副本演练、真实库逐表对照及线上 API 核验数据行为。
- 文档：本审查记录来源、判断及执行结果，待办已清退，运行态记录已同步。安装与配置方式没有变化，无新增 ADR 或智能体规则。
